

## Setup (Firebase)

This repo expects Firebase config files to be provided locally and **not committed**.

Required files:
- `android/app/google-services.json`
- `ios/Runner/GoogleService-Info.plist`
- `lib/firebase_options.dart` (generated by FlutterFire CLI)

Template files (checked in):
- `android/app/google-services.json.example`
- `ios/Runner/GoogleService-Info.plist.example`
- `lib/firebase_options.dart.example`
- `firebase.json.example`

Steps:
1. Install Firebase CLI and FlutterFire CLI.
2. Authenticate Firebase CLI:
   - `firebase login`
3. Configure FlutterFire:
   - `flutterfire configure --platforms=android,ios,web`
4. Verify generated files exist in the locations above.

Notes:
- `firebase.json` is ignored to keep project identifiers out of VCS.
- Web uses `lib/firebase_options.dart` at runtime.
